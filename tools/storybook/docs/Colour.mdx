# Colour

Every value on this page is read from the running stylesheet, not from a list kept alongside it. The
token names and the theme columns come from the CSSOM; the values come from `getComputedStyle` on a
probe element, so what you see is what the browser resolved — `var()` chains followed and the theme
cascade applied. Adding a token or a whole theme to `tools/sass/global/_variables.scss` shows up here
on the next build.

## Buttons

Button tokens (`--button-*`) are declared once on `:root` rather than per theme, so they are the same
in every theme by design and there is no matrix to show. They are listed in the ramps above.

## Using these

- Reach for a semantic token (`--bg-default`, `--fg-muted`) over a ramp token (`--gray-500`). The
  semantic one follows the theme; the ramp one does not.
- A section sets its theme through Sanity, which writes `data-theme` on the section element. Nothing
  in a component needs to know which theme is active.
- If a colour you need has no token, add it to `_variables.scss` for every theme rather than writing
  a literal in a component — a hardcoded hex is invisible to this page and to the theme switcher.
